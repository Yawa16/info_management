Developer handoff quick reference

Full handoff Markdown

Token and implementation guardrails

Color, type, spacing, radius, elevation, focus, and component patterns use Task 1 tokens. Use the complete token map, permission matrix, data fields, microcopy, acceptance checks, changes, gaps, and questions in the companion handoff.

Persistent sign-in

Invalid credentials stay neutral. Inactive and Blocked are announced only after identity is verified.

Request vs. Add

Public registration stays User/Inactive pending Admin or Superadmin approval. Staff Add creates an approved account with a temporary password.

Role gate

Admins manage Users; Superadmins manage Users and Admins. Users have no User Management access.

Soft delete

Deleted is recoverable, stamped, and separate from Active/Inactive/Blocked status.
