Assumptions and pending decisions

New email and Google accounts are User / Inactive. A Superadmin approves access. Registration never grants ERP access.

Email registration: submit name/email → Superadmin review → if approved, set password from emailed link → Sign In. Google: OAuth identity → pending approval → Google Sign In after approval.

Existing DEV guidance defaults signups to Superadmin; this conflicts with User/Inactive and must be reconciled before implementation.

Password requirements, lockout, token expiry, resend cooldown, registration availability, and Remember me duration are pending product/security decisions.

Flow overview
